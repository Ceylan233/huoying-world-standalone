# 安装与使用说明

## 下载前

- 确认下载的版本与自己的需求一致；
- 检查磁盘剩余空间，解压通常需要大于压缩包数倍的空间；
- 下载完成后按 `VERSIONS.md` 中记录的 SHA-256 校验文件；
- 升级或替换版本前，备份存档、数据库和自定义配置。

## 推荐安装方式

1. 将压缩包解压到独立目录，不要直接在压缩包中运行程序。
2. 尽量避免安装到系统目录、同步盘或需要管理员权限的目录。
3. 阅读版本包内附带的启动说明。
4. 按说明先启动服务端，再启动对应客户端或登录器。
5. 首次运行时不要立即覆盖已有存档。

## 常见排查顺序

遇到无法启动、无法登录或端口占用时，依次检查：

1. 压缩包校验值是否正确；
2. 文件是否完整解压；
3. 服务端进程是否已经启动；
4. 所需端口是否被其他程序占用；
5. 客户端和服务端是否来自同一版本；
6. 防火墙或安全软件是否拦截本地进程；
7. 修改配置后是否引入格式错误。

提交问题时请附上准确版本号、完整报错和复现步骤，不要公开任何密码、密钥或个人存档。
