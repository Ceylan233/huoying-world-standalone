# 2.2.1 登录器高 DPI 缩放修复

## 问题

`2.2.1（九月）`的 `NyaLauncher` 在高 DPI 或较低有效逻辑分辨率下存在以下问题：

- 主窗口尺寸由固定内容自动决定，部分内容可能超出屏幕可视区域；
- 自定义透明无边框窗口的四边和四角没有缩放命中区域；
- 鼠标移动到窗口边缘时不显示缩放光标，也无法拖动调整窗口尺寸。

## 已验证环境

- 客户端发行包：火影世界单机端 2.2.1（九月）
- 登录器界面版本：v2.2.0
- `NyaLauncher` 程序集版本：2.1.2.0
- 操作系统：Windows 10 家庭中文版 22H2（10.0.19045，x64）
- 显示器物理分辨率：2560x1600 @ 60 Hz
- Windows 显示缩放：200%（192 DPI）
- WPF 有效逻辑分辨率：1280x800
- .NET Desktop Runtime：8.0.29 x64

物理分辨率较高并不代表 WPF 一定拥有同等大小的布局空间。Windows 在 200% 缩放下会将
2560x1600 映射为约 1280x800 个设备无关像素，因此固定尺寸窗口仍可能显示不全。

## 复现步骤

1. 将 Windows 显示缩放设置为 200%。
2. 启动本地服务和 `NyaMicroClient/NyaLauncher.exe`。
3. 观察登录器窗口是否超出有效工作区。
4. 将鼠标移动到窗口四边和四角并尝试拖动。

原版窗口无法从边缘拖动缩放，在有效逻辑分辨率不足时可能看不到完整内容。

## 修复方案

- 将主窗口从内容自动定尺寸改为手动尺寸，并启用窗口缩放；
- 使用等比例适配容器承载原有界面，窗口改变时保持全部内容可见；
- 通过 `WM_NCHITTEST` 为四边和四角提供标准 Windows 缩放区域；
- 使用系统缩放光标和原生窗口拖动行为；
- 设置 `760x560` 的最小窗口尺寸，避免控件缩小到无法操作。

缩放支持的可审查源码位于：

`patches/2.2.1/launcher-resize/ResizableWindowSupport.cs`

## 安装

1. 完全退出 `NyaLauncher.exe`。
2. 备份 `NyaMicroClient/NyaLauncher.dll`。
3. 使用仓库中的修复版 `NyaLauncher.dll` 覆盖原文件。
4. 重新启动登录器。

只需要替换 DLL，不需要替换 `NyaLauncher.exe` 或本地服务程序。

## 回退

退出登录器后，将备份的原版 `NyaLauncher.dll` 放回 `NyaMicroClient` 目录即可。

## 验证结果

- `800x600` 和 `1180x740` 窗口尺寸下内容保持完整；
- 四边与四角均返回对应的标准 Windows 缩放命中值；
- 鼠标位于边缘时显示系统双向缩放光标；
- 登录器正常启动和响应；
- 本地登录接口、登录注册逻辑及游戏启动流程未作修改。

## 已知限制

- 低分辨率下采用等比例缩放，文字和控件也会相应变小；
- 当前主要在 Windows 10、200% DPI 环境验证；
- 建议继续补测 100%、125%、150%、175% DPI，以及 1366x768 和 1920x1080 等环境。
