# 火影世界单机端公共资料库

这是一个面向普通玩家、研究者和维护者长期开放的“火影世界单机端”公共资料库，用于集中整理可用版本、安装说明、更新记录、故障排查资料和非商业维护成果。

本仓库不是某一个版本的临时下载页。`2.2.1（九月）`是当前首个收录版本，后续版本、补丁和文档将继续在这里统一维护。

## 下载方式

### 直接下载

进入 `res/` 目录，选择需要的版本文件下载。大型文件由 Git LFS 保存。

### 克隆完整仓库

请先安装 Git 和 Git LFS，然后运行：

```bash
git lfs install
git clone https://github.com/Ceylan233/huoying-world-standalone.git
```

如果只需要某个版本，建议直接下载对应压缩包，避免克隆全部历史资源。

## 快速开始

1. 下载需要的版本并核对 SHA-256。
2. 解压到不含特殊权限限制的独立目录。
3. 阅读压缩包内说明和 [安装与使用说明](docs/使用说明.md)。
4. 启动前备份自己的存档和配置。
5. 遇到问题时记录版本号、操作系统、报错文字和复现步骤，再提交 Issue。
